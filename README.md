# Shell Computing Solutions ComputerCraft Library

This is a public code repository for the fictional company,
Shell Computing Solutions (SCS).

All relevant code is contained within the `lua` directory,
with additional API definitions defined in the `lib` directory.

## Testing

All code is written using the [EmmyLua Language Server][1] and
tested either through the [CCEmuX ComputerCraft emulator][2] or
(for more involved testing) in Minecraft itself.

This repository bundles a script (`emulator.sh`) that automates downloading
and running CCEmuX should you want to test code locally.

[1]: https://github.com/EmmyLuaLs/emmylua-analyzer-rust/
[2]: https://emux.cc/
